mark [option] [name] [value]
----------------------------------------

[option] - опция:
 - add  - [name] [value] - создать маркер
 - edit - [name] [value] - изменить маркер (системные тоже)
 - list -                - показать все маркеры и их значения

[name] - имя (строка)

[value] - исполняемое python выражение как динамическое значение
